# Brandsta Custom Code — CAPS Engine

The dedicated, isolated headless data sync engine for **Hotel CAPS** (`caps.brandsta.cc`).

## Overview

This Nuxt/Vue SPA provides the specialized interface that connects to the Hotel CAPS WordPress instance via the REST API.

It is purpose-built to handle custom data flows, such as updating Menu Specials and other client-managed content structures.
